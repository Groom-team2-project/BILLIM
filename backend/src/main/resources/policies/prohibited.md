title: 빌려주면 안 되는 물품
version: 2026-10-13
---
안전·위생·법적 사유로 아래 품목은 등록할 수 없어요. 등록되더라도 신고를 받으면 비공개·삭제되고, 반복되면 이용이 제한돼요.

| 분류 | 예시 | 금지 이유 |
| --- | --- | --- |
| 위생·신체 접촉 | 속옷, 수영복, 면도기, 칫솔, 렌즈·마스카라 | 감염·위생 위험으로 공용 부적절 |
| 의약품·건강 | 상비약, 체온계, 의료기기, 건강기능식품 | 오용 시 건강 위해, 관련 법 규제 |
| 주류·담배 | 술, 담배, 전자담배 | 청소년보호·유통 제한 |
| 위험물 | 가스·인화성 물질, 고위험 장비, 칼류 | 사고·부상 위험 |
| 고가·고위험 자산 | 명품, 고가 카메라·드론, 귀금속 | 분실·파손 시 보증금 없는 구조상 분쟁 위험 |
| 생명·법 위반 | 반려동물, 처방·불법 물품, 위조품 | 대여 대상이 아니거나 법에 어긋남 |

**판단 기준** — 몸에 직접 닿거나 먹는 것, 사고·법적 위험이 있는 것, 잃어버렸을 때 돈으로 물어줘야 할 만큼 비싼 것은 무료·무보증금 서비스에 맞지 않아요. 애매하면 등록 전에 '문의하기'로 확인해 주세요.
