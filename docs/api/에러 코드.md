# 에러 코드

> 버전 : v0.1.0\
> 수정일 : 2026.09.29

> 정렬 규약: HTTP 상태 코드 오름차순 → 같은 코드 안에서는 흐름 순. \
> 오류 응답 형식은 [API 명세서 0장](API%20명세서.md) 참조.

## 공통 (global)

| 코드 | 의미 | HTTP |
| --- | --- | --- |
| INVALID_REQUEST | 필수값·날짜 쌍·길이·알 수 없는 필드·페이지·상호 배타 커서 오류 | 400 |
| UNAUTHENTICATED | 세션 없음·만료·폐기 | 401 |
| CSRF_INVALID | 변경 요청의 CSRF 토큰 불일치 | 403 |
| FORBIDDEN | 소유자·당사자·관리자 역할 부족 | 403 |
| RESOURCE_NOT_FOUND | 없는 대상, 타 동네·비공개 등 존재 비노출 | 404 |
| VERSION_CONFLICT | expectedVersion 불일치 (`currentVersion` 제공) | 409 |
| INVALID_STATE_TRANSITION | 현재 상태에서 허용하지 않는 명령 | 409 |
| IDEMPOTENCY_KEY_REUSED | 같은 Idempotency-Key를 다른 요청 내용으로 사용 | 409 |
| RATE_LIMITED | 사용자/주소 기준 요청 제한 | 429 |
| RETRYABLE_CONFLICT | 잠금·데드락 제한 재시도 소진 | 503 |
| DEPENDENCY_UNAVAILABLE | 외부 인증·지도 연동 등 의존 장애 | 503 |
