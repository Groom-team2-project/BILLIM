# 정책 및 상태

> 모든 값에 근거를 함께 기록한다. 근거 없이 정한 값은 `임시`로 표기하고 별도 논의한다.
> 근거의 `[R06](도메인%20가이드.md#c-대여약속--박소빈)` 같은 ID와 `결정 '…'`은 [도메인 가이드](도메인%20가이드.md) 항목. `STATUS`·`POLICIES.*`는 [프로토타입](../prototype/billim-prototype.html) 화면 코드의 데이터 이름. `ERD`·`API`는 [도메인 및 DB 설계](../erd/도메인%20및%20DB%20설계.md)·[API 명세서](../api/API%20명세서.md).

## 1. 대여 상태

저장 상태 7종. 화면·API·DB에서 같은 값을 사용한다.

| 상태 | 의미 | 진입 조건 | 근거 |
| --- | --- | --- | --- |
| `REQUESTED` 요청 | 빌리는 사람이 기간을 정해 요청함 | 대여 요청 생성 | STATUS |
| `APPROVED` 승인 | 소유자가 요청을 승인함 | 소유자 승인. 겹침 재검사 통과 | [R06](도메인%20가이드.md#c-대여약속--박소빈) |
| `ACTIVE` 대여 중 | 물건이 전달됨 | 소유자의 전달 확인 | [R09](도메인%20가이드.md#c-대여약속--박소빈) |
| `RETURNED` 반납 완료 | 반납이 확인됨 | 소유자의 반납 확인. 실제 확인 시각 기록 | [R10](도메인%20가이드.md#c-대여약속--박소빈) |
| `EXPIRED` 요청 만료 | 승인 없이 요청 마감이 지남 | 시스템 전이. `request_expires_at`(시작일 다음 날 KST 00:00) 경과 | ERD, API |
| `REJECTED` 거절 | 소유자가 요청을 거절함 | 소유자 거절. 사유 선택(충돌 거절은 사유 필수) | [R08](도메인%20가이드.md#c-대여약속--박소빈) |
| `CANCELED` 취소 | 요청자가 요청을 거둠 | 요청자 취소. 취소 가능한 상태에서만 | [R05](도메인%20가이드.md#c-대여약속--박소빈) |

- 연체(OVERDUE)는 저장 상태가 아니라 파생 표시다. `ACTIVE` + `due_at` 경과이며 API는 `overdue` boolean으로 전달한다. (ERD, API)
- `frontend/DESIGN_SYSTEM.md` §5는 OVERDUE 포함·EXPIRED 없음 — 화면 표시 결정과 함께 갱신 필요.

## 2. 대여 상태 전이

```text
REQUESTED ──승인(소유자)──> APPROVED ──전달 확인(소유자)──> ACTIVE ──반납 확인(소유자)──> RETURNED
    │
    ├──거절(소유자, 사유)──> REJECTED
    ├──취소(요청자)──────> CANCELED
    └──요청 마감 경과(시스템)──> EXPIRED
```

- `REJECTED`·`CANCELED`·`RETURNED`·`EXPIRED`는 종료 상태. 이후 전이 없음. (완료 후 재승인, 반납 전 취소 같은 잘못된 전이는 서버에서 차단)
- 연체 표시는 진행 단계상 `ACTIVE`와 같은 칸. 별도 상태가 아니라 파생 표시.
- 승인 시 소유자 권한·현재 상태·날짜 겹침을 같은 정합성 경계에서 재검사한다. 같은 물건의 겹치는 요청을 동시에 승인해도 성공은 한 건.
- 승인해도 같은 물건의 다른 `REQUESTED`는 자동 거절하지 않는다. (ERD)

## 3. 대여 기간 규칙

| 항목 | 값 | 의미 | 근거 |
| --- | --- | --- | --- |
| 시간 단위 | 날짜(일) | 시각 없음. 약속(전달·반납)만 시·분을 가짐 | [R02](도메인%20가이드.md#c-대여약속--박소빈) |
| 경계 | 양끝 포함 | 시작일과 반납일 모두 대여 기간에 포함 | [결정 '기간 경계'](도메인%20가이드.md#결정-기간-경계) |
| 겹침 판정 | `기존시작 ≤ 신규종료 AND 신규시작 ≤ 기존종료` | 하루라도 겹치면 겹침 | [결정 '기간 경계'](도메인%20가이드.md#결정-기간-경계) |
| 대기 겹침 | 허용 | `REQUESTED`끼리는 기간이 겹쳐도 됨 | [결정 '겹치는 대기 요청'](도메인%20가이드.md#결정-겹치는-대기-요청) |
| 승인 겹침 | 금지 | `APPROVED` 이상이 점유한 기간과 겹치는 승인 불가 | [결정 '겹치는 대기 요청'](도메인%20가이드.md#결정-겹치는-대기-요청) |
| 연체 중 신규 전달 | 불허 | 미반납 물건은 새 승인·전달 불가 | [결정 '연체와 후속 대여'](도메인%20가이드.md#결정-연체와-후속-대여) |
| 반납 후 점유 | 유지 | `RETURNED`도 종료일까지 기간 점유 유지 | ERD |
| 기간 변경 | 없음 | 대여 기간 변경은 별도 기능. 암묵 제공하지 않음 | [결정 '약속과 날짜 변경'](도메인%20가이드.md#결정-약속과-날짜-변경) |
| 검색 가능 판정 | 기간 전체 가능 + 승인 겹침 없음 | 조회 시점 기준. 승인 시 재확인 | [P11](도메인%20가이드.md#b-물건검색--주정현) |

## 4. 물품 상태

| 상태 | 의미 | 진입 조건 | 근거 |
| --- | --- | --- | --- |
| `PUBLIC` 공개 중 | 검색·요청 가능 | 등록 완료 | [P01](도메인%20가이드.md#b-물건검색--주정현), ERD |
| `HIDDEN` 공개 중지 | 검색·신규 요청 불가. 진행 중 대여는 유지 | 소유자 중지 | [P01](도메인%20가이드.md#b-물건검색--주정현), ERD, 화면 '지금은 볼 수 없는 물건' |
| `DELETED` 삭제 | 논리 삭제. 목록·상세 비노출, 거래 기록은 보존 | 소유자 삭제. 진행 요청·거래가 있으면 불가 | ERD, API |
