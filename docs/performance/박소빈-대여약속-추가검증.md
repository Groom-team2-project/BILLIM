- 대여·약속 관련 기존 테스트 166건: 실패·오류·건너뜀 0. Testcontainers MySQL 사용.

- 현재 조건의 회귀·응답 동일성·DB 정합성 검증 통과. 운영 성능·최대 수용 사용자 수·장시간 안정성 보장 불가.
